# Guatemala Tech Market Context

## When to Use
Trigger this skill when generating the sample data for the frontend UI.

## Market Context & Guidelines
1. **Sample Data:** When generating the placeholder sample data, use realistic local scenarios (e.g., job titles like "Desarrollador Full Stack" or "Ingeniero de Datos", and companies like "Telus", "Banco Industrial", or local startups).
2. **Location Default:** Always ensure the location defaults to "Guatemala".
3. **Salary Realism (GTQ / USD):** Understand that salaries in the Guatemalan tech market are often discussed in Quetzales (GTQ) or USD. Adjust the salary expectations based on this local reality, not US-centric Silicon Valley salaries.
4. **Avoid Generating Sample Data With Generic Names:** Use well known companies. Avoid companies with generic names which might be confused with other similar ones.
