Cover Letter Generator

Split Brain Architecture with local heuristic fallbacks and cloud LLMs

Client: The Local Brain

  • • Extracts Glassdoor salary ranges using Regex.
  • • Analyzes requested salary with IF statements.
  • • Restores User Name before rendering UI.
  • • Never leaks current salary or name.

Server: Orchestration

  • • Connects to 3rd party APIs.
  • • Hides API Keys from the public.
  • • Sanitizes payloads received from APIs.

Cloud: The Generator

  • • Uses Gemini 3.8 Flash for creative text.
  • • Scrapes LinkedIn experience via Proxycurl.
  • • Only receives sanitized, anonymous contexts.
